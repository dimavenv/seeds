# 🛠️ Настройка магазина и админа (без программирования)

Всё делается в личном кабинете **Supabase** через браузер. Терминал не нужен.

## Шаг 1. Создать таблицы и демо-товары

1. Зайдите на [supabase.com](https://supabase.com) → откройте свой проект.
2. Слева выберите **SQL Editor** → **New query**.
3. Откройте файл `supabase/setup.sql` из этого репозитория, скопируйте **всё**
   его содержимое и вставьте в окно запроса.
4. Нажмите **Run** (или Ctrl/Cmd + Enter). Должно появиться «Success».

Это создаст таблицы, права доступа, хранилище для фото и добавит примеры товаров.

## Шаг 2. Разрешить вход без подтверждения почты

1. Слева **Authentication** → **Sign In / Providers** (или **Providers**) → **Email**.
2. Выключите **Confirm email** (подтверждение по почте) → **Save**.

(Иначе после регистрации нужно будет подтверждать письмо, что неудобно.)

## Шаг 3. Создать пользователя-администратора

1. Слева **Authentication** → **Users** → **Add user** → **Create new user**.
2. Введите **email** и **пароль**, поставьте галочку **Auto Confirm User** → создать.

## Шаг 4. Выдать пользователю права админа

1. Снова **SQL Editor** → **New query**.
2. Откройте файл `supabase/make-admin.sql`, вставьте его содержимое.
3. Замените `ВАШ_EMAIL@example.com` (в двух местах) на email из шага 3.
4. **Run**. Внизу должна появиться строка с `role = admin`.

## Шаг 5. Подключить сайт к базе

Возьмите ключи: **Project Settings → API**:

- `Project URL`
- `anon public` ключ
- `service_role` ключ (секретный)

Впишите их:

- **Локально:** создайте файл `.env.local` (по образцу `.env.local.example`).
- **На Vercel:** Project → Settings → Environment Variables — добавьте те же три
  переменные:
  - `NEXT_PUBLIC_SUPABASE_URL`
  - `NEXT_PUBLIC_SUPABASE_ANON_KEY`
  - `SUPABASE_SERVICE_ROLE_KEY`

## Шаг 6 (необязательно). Автоподстановка индекса в заказе (DaData)

В оформлении заказа адрес вводится по полям (индекс, регион, город, улица, дом,
квартира). Если подключить **DaData**, при вводе города/улицы/дома появляются
подсказки, а **индекс подставляется автоматически**.

1. Зарегистрируйтесь на [dadata.ru](https://dadata.ru) (бесплатно, 10 000
   запросов в день).
2. **Профиль → API → «Ключ для сервиса подсказок»** — скопируйте этот ключ
   (нужен именно ключ подсказок, не «секретный ключ»).
3. Добавьте переменную:
   - **Локально:** в `.env.local` строку
     `NEXT_PUBLIC_DADATA_TOKEN=ваш-ключ-подсказок`.
   - **На Vercel:** Environment Variables → `NEXT_PUBLIC_DADATA_TOKEN`.
4. Перезапустите `npm run dev` (или передеплойте на Vercel).

Без этого ключа поля адреса просто заполняются вручную — заказ всё равно
оформляется.

## Готово 🎉

Откройте сайт → **/login** → войдите email и паролем из шага 3 → откроется
**личный кабинет** (`/account`) с историей заказов. Если вы администратор, там
будет кнопка **«Админ-панель»** (`/admin`) — добавлять товары с фото, видеть
заказы и менять их статусы.

### Если пишет «Доступ запрещён» при входе в админку
Роль администратора хранится в токене входа (JWT). Чтобы её выдать:

1. Выполните `supabase/make-admin.sql` со своим email (Supabase → SQL Editor) —
   он проставляет роль `admin` и в профиле, и в токене.
2. **Выйдите из аккаунта и войдите снова** — роль попадёт в новый токен.

После этого `/admin` открывается надёжно, без лишних запросов к базе (поэтому он
работает даже на медленном интернете). Если всё равно «Доступ запрещён» — значит
вы вошли не тем email, для которого выдали права.

### Если всё долго грузится и вход кидает обратно на /login
Это значит, что сайт не может достучаться до базы Supabase. Проверьте:

1. **Проект не на паузе.** На бесплатном тарифе Supabase усыпляет проект после
   ~7 дней простоя. Откройте [supabase.com](https://supabase.com) → ваш проект →
   если вверху написано **Paused**, нажмите **Restore / Resume** и подождите
   1–2 минуты.
2. **Откройте `/api/health`** на сайте (например `http://localhost:3000/api/health`).
   - `{"ok":true,...}` — база доступна.
   - `{"ok":false,...}` — база недоступна; смотрите поле `error`.
3. **Сверьте ключи** в `.env.local` с **Project Settings → API**: `Project URL`,
   `anon public`, `service_role`. Без лишних пробелов и переносов строк.
   После правок перезапустите `npm run dev`.
