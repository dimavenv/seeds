# 🛠️ Настройка магазина и админа (без программирования)

Всё делается в личном кабинете **Supabase** через браузер. Терминал не нужен.

## Шаг 1. Создать таблицы и демо-товары

1. Зайдите на [supabase.com](https://supabase.com) → откройте свой проект.
2. Слева выберите **SQL Editor** → **New query**.
3. Откройте файл `supabase/setup.sql` из этого репозитория, скопируйте **всё**
   его содержимое и вставьте в окно запроса.
4. Нажмите **Run** (или Ctrl/Cmd + Enter). Должно появиться «Success».

Это создаст таблицы, права доступа, хранилище для фото и добавит примеры товаров.

## Шаг 2. Разрешить вход без подтверждения почты

1. Слева **Authentication** → **Sign In / Providers** (или **Providers**) → **Email**.
2. Выключите **Confirm email** (подтверждение по почте) → **Save**.

(Иначе после регистрации нужно будет подтверждать письмо, что неудобно.)

## Шаг 3. Создать пользователя-администратора

1. Слева **Authentication** → **Users** → **Add user** → **Create new user**.
2. Введите **email** и **пароль**, поставьте галочку **Auto Confirm User** → создать.

## Шаг 4. Выдать пользователю права админа

1. Снова **SQL Editor** → **New query**.
2. Откройте файл `supabase/make-admin.sql`, вставьте его содержимое.
3. Замените `ВАШ_EMAIL@example.com` (в двух местах) на email из шага 3.
4. **Run**. Внизу должна появиться строка с `role = admin`.

## Шаг 5. Подключить сайт к базе

Возьмите ключи: **Project Settings → API**:

- `Project URL`
- `anon public` ключ
- `service_role` ключ (секретный)

Впишите их:

- **Локально:** создайте файл `.env.local` (по образцу `.env.local.example`).
- **На Vercel:** Project → Settings → Environment Variables — добавьте те же три
  переменные:
  - `NEXT_PUBLIC_SUPABASE_URL`
  - `NEXT_PUBLIC_SUPABASE_ANON_KEY`
  - `SUPABASE_SERVICE_ROLE_KEY`

## Готово 🎉

Откройте сайт → **/login** → войдите email и паролем из шага 3 → откроется
панель **/admin**. Там можно добавлять товары с фото, видеть заказы и менять
их статусы.
