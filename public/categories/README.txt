Картинки категорий для главной страницы.

Положите сюда квадратные изображения с именами по категории (.jpg):
  tomaty.jpg          — Томаты
  perec-sladkiy.jpg   — Перец сладкий
  perec-chili.jpg     — Перец чили
  baklazhany.jpg      — Баклажаны
  kukuruza.jpg        — Кукуруза
  kartofel.jpg        — Картофель
  dynya.jpg           — Дыня
  arbuz.jpg           — Арбуз

Рекомендуемый размер: квадрат ~400x400px. Картинка показывается
кружком на плитке категории. Если файла нет — показывается эмодзи.

Как загрузить на GitHub: откройте папку public/categories в репозитории
на github.com → «Add file» → «Upload files» → перетащите картинки
с указанными именами → Commit.
