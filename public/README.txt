Логотип сайта.

Положите файл логотипа сюда с именем:
  logo.png

Рекомендации:
- формат .png с прозрачным фоном (или .png без прозрачности);
- примерно квадрат, ~512x512px (показывается рядом с названием в шапке
  и в подвале, маленьким значком);
- если файла нет — показывается стандартный логотип-помидор.

Как загрузить на GitHub: откройте папку public в репозитории на
github.com → «Add file» → «Upload files» → перетащите файл logo.png →
Commit.

------------------------------------------------------------------

Иконка вкладки браузера (favicon) — по желанию.

Чтобы во вкладке браузера показывался ваш значок, добавьте файл
  app/icon.png
(квадрат ~512x512px). Next.js подхватит его автоматически как иконку
сайта. Загружается так же через «Add file → Upload files», но в папку
app, а не public.
