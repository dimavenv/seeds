Логотип сайта.

Положите файлы логотипа сюда с именами:
  logo.webp        — для светлой темы
  logo-dark.webp   — для тёмной темы

Рекомендации:
- формат .webp (весит в разы меньше .png при том же качестве);
- прозрачный фон, примерно квадрат ~512x512px (показывается рядом с
  названием в шапке и в подвале);
- если файла нет — показывается стандартный логотип-помидор.

Здесь же лежат иконки способов доставки:
  dostavka-ozon.webp, dostavka-pochta.webp

Как загрузить на GitHub: откройте папку public в репозитории на
github.com -> «Add file» -> «Upload files» -> перетащите файлы -> Commit.

Иконка вкладки браузера (favicon).

Значок вкладки лежит НЕ здесь, а в папке app:
  app/icon.png         — иконка вкладки
  app/apple-icon.png   — иконка для iPhone/iPad

ВАЖНО: именно .png, не .webp. Next.js распознаёт по имени файла только
.ico/.jpg/.jpeg/.png/.svg — файл app/icon.webp он просто не увидит, и
сайт останется без иконки вовсе. Иконка для Apple в .webp не работает и
в самой iOS. Эти два файла оставляйте в .png, просто сделайте их
поменьше (достаточно 512x512px и ~30 КБ).

Файл public/favicon.png не используется ничем — его можно удалить.
