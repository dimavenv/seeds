# 🔐 Вход и автоматическое создание кабинета

У покупателей нет отдельной регистрации и входа через Яндекс ID или VK ID.
Страница `/login` принимает только email и пароль.

## Как появляется кабинет покупателя

Покупатель оформляет первый заказ без аккаунта. После подтверждения онлайн-оплаты
сайт (`lib/auto-account.ts`; для оплаты при получении — после принятия заказа):

1. Ищет существующий аккаунт по email из заказа и, если находит, привязывает к
   нему заказ.
2. Если аккаунта нет, создаёт его, переносит ФИО и телефон из заказа и
   задаёт случайный пароль.
3. Отправляет логин и пароль на email покупателя. Сменить пароль можно в
   «Настройки аккаунта → Безопасность», введя текущий пароль из письма.

Аккаунт и связь с заказом сохраняются независимо от результата отправки письма.
Пока SMTP не принял письмо, пароль хранится зашифрованным в скрытом поле
`users.welcome_credentials`. После отправки поле очищается. Повторный callback,
плановая уборка и кнопка в админке повторяют доставку, не меняя пароль.
Ключ очереди берётся из `DATA_ENCRYPTION_KEY`, иначе из `PB_ADMIN_PASSWORD`.
Старые оплаченные заказы без аккаунта можно исправить через «Админка → Аккаунты →
Восстановить доступ по оплаченным заказам». За запуск обрабатывается до 50 заказов.

Если покупатель забыл пароль, он запрашивает одноразовую ссылку на
`/password-reset`. Ссылки хранятся в `password_reset_tokens` только как SHA-256,
имеют срок действия и после успешной смены пароля повторно не работают.

Анонимное создание пользователей напрямую в PocketBase закрыто (`createRule:
null`). OAuth2 в `pocketbase/pb_schema.json` отключён, а публичных OAuth и
регистрационных API-маршрутов в приложении нет.

## Применить на сервере

```bash
cd /var/www/seeds/seeds
git pull
npm run db:schema
bash deploy/update.sh
```

Импорт схемы отключает ранее настроенные OAuth-провайдеры в PocketBase. Старый
адрес `/register` перенаправляет на `/login` и объясняет, что кабинет создаётся
при первом заказе.

## Капча и восстановление пароля

Yandex SmartCaptcha продолжает защищать вход, восстановление пароля, поддержку
и оформление заказа. Для включения задайте в `.env.production`:

```dotenv
NEXT_PUBLIC_SMARTCAPTCHA_SITE_KEY=клиентский-ключ
SMARTCAPTCHA_SERVER_KEY=серверный-ключ
```

После изменения публичного ключа выполните `bash deploy/update.sh`.

Администраторов создавайте вручную в PocketBase и назначайте им `role = admin`.
Покупатель не может получить эту роль через заказ.
